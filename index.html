ABOUT

应用介绍

园枢是一款面向山西晋中理工学院师生、考生与家长的校园信息聚合工具，让校园官方信息触手可及。

1园枢是什么

园枢是一款面向山西晋中理工学院师生、考生与家长的校园信息聚合应用。它把分散在学校官网各栏目、各子站中的新闻资讯、通知公告、院系专业、招生讯息、校园风光等内容汇集到一个应用里，打开园枢即可一览校园最新动态。

2园枢解决什么问题

过去获取学校信息需要在多个网站之间跳转查找，重要通知容易错过。园枢通过统一聚合与本地通知，把要闻、公告、活动、校长信箱回复等动态集中呈现并主动提醒；即使网络不佳，也能依靠本地缓存正常阅读内容。

3园枢给谁用

在校师生可用它掌握校园资讯、查询院系专业与机构信息；考生与家长可在招生季了解招生讯息、专业介绍与办学数据；校友与社会公众也能方便地关注学校荣誉、党建动态与校园影像。

4轻量、可信、尊重隐私

园枢不要求注册登录、不收集个人信息、不含任何支付功能。浏览偏好、收藏与设置仅保存在设备本地；需要联网时只拉取学校公开信息用于展示，卸载应用即可清除全部本地数据。

FEATURES

功能特性

六大核心能力，覆盖校园信息获取、查询与个性化阅读的完整场景。

01

校园信息聚合首页

聚合学校要闻、通知公告、校园荣誉、教师风采、学生故事、校园视频、风光图集等模块，一屏掌握校园动态。各模块支持排序与隐藏，把最关心的内容放到最前面。

02

新闻资讯与消息中心

资讯按分类筛选，支持搜索、收藏、已读标记与阅读时长预估；五通道消息中心汇总新闻、校长信箱、学校概况、党建专题与收藏更新，本地通知及时提醒，重要内容不再错过。

03

院系与专业查询

覆盖学校全部教学机构与 44 个本科专业，从院系列表直达院系详情与专业介绍，帮助考生、家长与在校师生快速了解学校学科布局。

04

学校概况一站式

学校简介、现任领导、校徽校名、宣传片、校园风光画廊与合作交流集中呈现，办学数据一目了然；校长信箱公开可查来信与回复，党建专题一站检索党建与思政内容。

05

招生资讯与校园生活

独立的招生讯息频道与专业介绍，招生季信息直达；校园视频、校园日历、教务图书等校园服务快捷通道与校史时间线，让在校生活更加便利。

06

安全与个性化

支持 Face ID / Touch ID 应用锁保护隐私内容；深浅色模式、多款主题色、6 档字号、屏幕常亮等个性化显示；内置 31 篇图文使用帮助，快速上手无障碍。

平台架构

SYSTEM & PRIVACY

系统与隐私信息

园枢坚持最小权限原则：只申请实现功能所必需的系统权限，所有个人数据仅保存在设备本地。

运行环境

  • 支持 iOS 26.0 及以上版本
  • 可在 iPhone 与 iPad 上运行
  • 应用体积轻量，界面完全本地渲染

系统权限及用途

  • Face ID / Touch ID：应用安全锁解锁，生物特征由系统安全芯片处理，园枢不获取、不存储
  • 相册（仅写入）：将校园风光、现任领导、校徽校名等公开图片保存到系统相册，不读取相册内容
  • 通知：校园资讯更新提醒，可随时在系统设置中关闭
  • 不申请：相机、麦克风、定位、通讯录、后台运行等权限

网络使用

  • 仅在用户同意后，联网拉取学校官网公开信息与官方公告文本用于展示
  • 无注册登录、无账号体系，不收集、不上传任何用户数据
  • 网络异常时自动降级为本地缓存与内置内容，离线可用

数据存储

  • 界面设置、收藏记录、已读标记、内容缓存与运行日志仅保存在设备本地
  • 敏感令牌使用系统钥匙串加密存储
  • 卸载园枢即可清除全部本地数据
