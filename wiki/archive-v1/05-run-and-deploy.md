# 05 · 运行与部署

## 1. 运行前提

| 项       | 要求                                         |
| -------- | -------------------------------------------- |
| 操作系统 | macOS / Windows / Linux 均可                 |
| 运行时   | 任意现代浏览器；本地建议 Python 3 或 Node.js |
| 依赖安装 | **无需** `npm install`、无锁文件、无环境变量 |
| 工作目录 | 仓库根目录（`index.html` 所在目录）          |
| 网络     | 本地预览不需要；线上访问需要                 |

---

## 2. 本地运行

### 方式 A：Python 静态服务器（推荐）

```bash
cd /Users/qinchao/Music/tools/garden-website
python3 -m http.server 8000
```

浏览器打开 `http://localhost:8000/`。

- 优点：路径、MIME、缓存行为与线上静态托管一致；
- 端口被占用时换成 `8000` 以外的端口，例如 `8080`；
- 停止：`Ctrl + C`。

### 方式 B：Node.js

```bash
cd /Users/qinchao/Music/tools/garden-website
npx serve .
```

按终端提示打开对应地址（通常是 `http://localhost:3000`）。首次执行 `npx` 会临时下载 `serve`，这不是项目依赖。

### 方式 C：直接打开文件

双击 `index.html` 或用浏览器打开 `file:///.../index.html`。

- 相对路径资源可以正常加载；
- 个别浏览器对 `file://` 的脚本/字体/安全策略更严格，行为可能与线上不同；
- 涉及跨页锚点（`index.html#features`）时，建议仍用方式 A。

### 2.1 可访问路径

| URL                  | 页面     |
| -------------------- | -------- |
| `/` 或 `/index.html` | 首页     |
| `/privacy.html`      | 隐私政策 |
| `/agreement.html`    | 用户协议 |
| `/assets/...`        | 图片资源 |
| `/beian/beian.png`   | 备案徽标 |
| `/styles.css`        | 样式表   |

服务器必须把仓库根目录作为站点根；如果把 `assets` 或 HTML 放到子目录，所有相对路径都会失效。

## 4. 部署

### 4.1 当前部署形态

> 下表依据远程仓库、线上域名与站点结构推断；发布分支与自定义域的具体值以 GitHub 仓库 **Settings → Pages** 为准。

| 项       | 值                                                      |
| -------- | ------------------------------------------------------- |
| 远程仓库 | `origin` → `https://github.com/kkkh/garden-website.git` |
| 发布分支 | `main`（推断）                                          |
| 托管     | GitHub Pages（静态）                                    |
| 站点根   | 仓库根目录（推断）                                      |
| 自定义域 | `https://jl.43322.cn`                                   |
| 构建命令 | 无                                                      |
| 发布产物 | 仓库文件本身                                            |

> 仓库内**没有** `CNAME` 文件、`.github/workflows` 或 Pages 配置文件。自定义域、HTTPS、发布分支均在 GitHub 仓库的 **Settings → Pages** 中配置，属于平台侧状态；换仓库或迁移托管时需要手工重建。

### 4.2 发布步骤

```bash
cd /Users/qinchao/Music/tools/garden-website

# 1. 确认改动范围
git status
git diff --stat

# 2. 本地验收（按第 3 节清单）

# 3. 提交
git add index.html styles.css privacy.html agreement.html assets wiki
git commit -m "描述本次改动"

# 4. 推送 main（推送即触发 Pages 发布）
git push origin main
```

推送后到 GitHub Actions / Pages 状态页确认构建完成（静态站点通常只需数秒到数分钟），再访问 `https://jl.43322.cn` 强制刷新验证。

### 4.3 首次在新环境启用 Pages

1. 仓库 **Settings → Pages**；
2. Source 选择 **Deploy from a branch**；
3. Branch 选择 `main`，目录选择 `/ (root)`；
4. 保存后等待首次发布；
5. 在 **Custom domain** 填入 `jl.43322.cn` 并保存；
6. 在域名服务商处按 GitHub 指引配置 DNS（子域通常为 CNAME，本仓库对应 `kkkh.github.io`，以 Pages 页面提示为准；裸域则用 A 记录）；
7. 等待 DNS 生效后勾选 **Enforce HTTPS**。

若使用自定义域，建议在仓库根目录补一个内容为 `jl.43322.cn` 的 `CNAME` 文件，避免平台设置丢失；当前仓库没有该文件。

### 4.4 缓存与发布

| 对象                   | 缓存策略               | 更新方式           |
| ---------------------- | ---------------------- | ------------------ |
| HTML                   | 平台默认（通常较短）   | 重新推送           |
| `styles.css?v=...`     | 查询串变化即视为新 URL | 修改首页版本号     |
| `styles.css`（文档页） | 无查询串，按平台默认   | 强刷或补版本号     |
| 图片                   | 按 URL 缓存，可能较长  | 换文件名最稳妥     |
| favicon                | 浏览器强缓存           | 改名或清理站点数据 |

**版本号约定**：`styles.css?v=YYYYMMDD-N`，日期为修改日，`N` 为当日第几次样式发布。当前值 `20261023-3`。只改 HTML/图片时不必改；改 CSS 时建议三页统一加同一版本号。

## 5. 故障排查

| 现象               | 可能原因                                    | 排查 / 解决                                                                    |
| ------------------ | ------------------------------------------- | ------------------------------------------------------------------------------ |
| 页面无样式         | CSS 路径错、服务器 MIME 错、缓存旧版本      | Network 看 `styles.css` 是否 200 且 `Content-Type: text/css`；强刷；检查 `?v=` |
| 图片全部 404       | 未以仓库根目录启动服务器                    | 在 `index.html` 同级启动；确认 URL 为 `/assets/...`                            |
| 个别图片 404       | 文件名大小写或编号不连续                    | 核对 `screenshot-01…22`、`flow-01…10`                                          |
| 轮播不动           | JS 报错、`#appCarousel`/`.cvr-img` 被改名   | 控制台看异常；核对 [03](03-key-code.md#1-html-关键结构) 的 DOM 契约            |
| 缩略图数量不对     | 旧截图注释被取消、增删图未同步文案          | 确认 DOM 内 `.cvr-img` 数量；更新 `#cvrTotal`、文案、11 列网格                 |
| 计数显示 0 或空白  | `#cvrCount` / `#cvrTotal` 被删              | 恢复节点                                                                       |
| 点击缩略图无反应   | `.cvr-thumb`/`data-i` 结构被改              | 保持 `data-i` 与事件委托                                                       |
| 锚点跳转被页头遮挡 | 删除了 `scroll-margin-top` 或改了页头高度   | 调整 `[id]` 的 86/150/180px                                                    |
| 文档页样式仍旧     | 文档页 CSS 无版本参数                       | 强刷；或给两页补 `?v=`                                                         |
| 移动端横向溢出     | 新增内容宽度超限、长英文/URL 未换行         | 检查 `overflow-x`；给长文本加 `word-break`                                     |
| 线上仍显示旧图     | CDN/浏览器缓存同名 URL                      | 换文件名并改 `src`；或等待缓存过期                                             |
| Pages 返回 404     | Pages 未启用、分支/目录选错、文件不在根目录 | 检查 Settings → Pages；确认 `index.html` 在根                                  |
| 自定义域打不开     | DNS 未生效、CNAME 配置错、HTTPS 未就绪      | `dig jl.43322.cn`；核对 Pages 自定义域设置                                     |
| 方向键不生效       | 舞台不在视口内                              | 滚动到截图区再试（设计如此）                                                   |
| 备案链接打不开     | 外链地址或查询参数变更                      | 手工在浏览器验证并更新三页                                                     |
