## 3. 目录结构

```text
garden-website/
├── index.html                     # 首页：产品介绍、功能、截图轮播、架构图、系统信息、关于
├── privacy.html                   # 隐私政策（文档型页面）
├── agreement.html                 # 用户协议（文档型页面）
├── styles.css                     # 全站唯一样式表（设计令牌 + 组件 + 响应式）
├── assets/
│   ├── icon.png                   # 应用图标 256×256
│   ├── screenshot-01.jpg … 22.jpg # 应用截图，全部 1284×2778
│   └── flow-01.png … flow-10.png  # 平台架构图，全部 1600×1240
├── beian/
│   └── beian.png                  # 公安备案徽标 20×20
├── wiki/                          # 本 Code Wiki（纯文档，不参与站点渲染）
├── .trae-html-share-packages/     # 3 个整站分享 ZIP（各约 17 MB，已入库）
├── .screenshots/.tmp/             # 空的本地临时目录（未纳入 Git）
├── .gitignore
└── .git/                          # main 分支，远程 origin
```

> `.screenshots/` 为空目录，Git 不跟踪空目录；`assets/jltp/` 当前不存在，仅出现在分享 ZIP 包内（原始 HEIC 素材）。

## 4. 五分钟开始

项目无需安装依赖，任选一种方式：

```bash
# 方式 A：Python 自带静态服务器（推荐，行为最接近线上）
cd /Users/qinchao/Music/tools/garden-website
python3 -m http.server 8000
# 打开 http://localhost:8000/

# 方式 B：Node.js 环境
npx serve .

# 方式 C：直接双击 index.html（相对路径可用，但个别浏览器对本地文件限制更严）
```

本地验收至少确认：

1. 首页 7 个导航项均可跳转（5 个页内锚点 + 2 个法律页）；
2. 截图轮播显示 `01 / 22`，左右箭头、缩略图、触摸滑动、方向键都能切换；
3. 隐私政策 / 用户协议可互相跳转并返回首页；
4. 页脚 ICP 与公安备案链接可打开；
5. 窄屏（≤640px）下导航换行、缩略图单行横向滚动，无横向溢出。

详细步骤见 [05 · 运行与部署](05-run-and-deploy.md)。

## 5. 核心事实与术语

| 术语 | 含义 |
| --- | --- |
| 园枢 | 应用名称，也是本站展示的主体；本站是应用的官网，不是应用本体 |
| 五个栏目 | 应用内的首页、资讯、院系、校园、我的（官网功能文案中的概念） |
| 三大专题 | 校长信箱、党建专题、学校概况（官网架构图中的概念） |
| 内容模块 | 首页 section，例如 `#features`、`#screenshots` |
| 设计令牌 | `styles.css` 顶部 `:root` 中的颜色、字体、圆角、阴影变量 |
| 轮播契约 | HTML 中 `.cvr-img` 的 `src` / `alt` / `data-cap` 与固定 class 组成的数据约定 |
| 备案信息 | 页脚 ICP 备案号与公安联网备案号，属于合规必需内容 |

## 6. 重要边界说明

- **本站不包含 iOS 应用源码**。仓库只有官网静态页面；页面中描述的「12 大服务中枢」「三级缓存」等是应用架构的展示文案与配图，本站不实现这些逻辑。
- **运行时不联网取数**。页面只加载同源本地文件，不向任何第三方发起请求；仅在用户主动点击备案外链时跳转到外部站点。
- **无用户数据采集**。没有 Cookie、`localStorage`、`sessionStorage`、埋点或登录。
- **无自动化测试**。验收依赖人工清单与静态检查；改动后请按 [05](05-run-and-deploy.md) 的清单回归。
- **文档与代码同步责任**：修改页面结构、资源数量、断点或脚本行为后，需同步更新本 Wiki 对应章节。
