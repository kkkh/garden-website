## 业务盲区逐项声明（第 13 项展开）

| 盲区           | 决策      | 理由                                                                                                  |
| -------------- | --------- | ----------------------------------------------------------------------------------------------------- |
| 国际化 / RTL   | ⛔ 不做   | 受众为单一中文高校群体；无需求证据；排版已用逻辑属性为未来预留（ADR-0008）                            |
| 浏览器兼容     | 🟡 部分   | 目标为现代浏览器；未对旧 Safari/IE 做 polyfill；已在 AS-07 声明，CI 仅 Chromium                       |
| 表单验证与恢复 | ➖ 不适用 | 站点无任何表单输入（无联系表单、无订阅）                                                              |
| 权限 / 登录态  | ➖ 不适用 | 无账号体系，隐私政策明确「无需注册登录」                                                              |
| 隐私合规       | ✅ 已处理 | 无 Cookie/无统计/无上传；主题偏好已在隐私政策中说明且可删除（ADR-0009）；备案信息保留                 |
| 第三方集成     | ⛔ 不做   | 无统计、无客服、无登录组件、无字体 CDN（隐私与供应链承诺）                                            |
| 邮件模板       | ➖ 不适用 | 无邮件发送功能；仅提供 `mailto:` 链接                                                                 |
| 打印样式       | ✅ 已实现 | `@media print`：隐藏导航/页脚/目录/交互元素，强制浅色，避免标题后断页；未做 PDF 分页人工复核（P2-02） |
| 弱网 / 离线    | 🟡 部分   | 图片懒加载 + 相邻预取 + HTML 短缓存；无 Service Worker（P2-07），断网不可访问                         |
| 灰度 / 监控    | ⛔ 不做   | 纯静态站；回滚基于 Git + 发布目录（rollback.md）；无监控告警（无资源与需求）                          |
