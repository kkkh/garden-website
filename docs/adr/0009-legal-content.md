# ADR-0009：法律文本的迁移方式与隐私事实补充

- 状态：已采纳
- 日期：2026-10-23

## 背景

v1 的隐私政策与用户协议是两页手写 HTML（各 9 章 / 7 章），样式由 `.doc-wrap` 统一控制。
v2 需要：

- 保留全部条款语义与章节编号，不改变开发者与用户之间的权利义务；
- 让长文具备目录、锚点、打印与更好的排版；
- 处理一个**事实不一致**：v2 在浏览器 `localStorage` 中保存主题偏好，而 v1 隐私政策声明「不收集任何数据」时并未包含这一点。

## 决策

1. **迁移到 Markdown + Content Collections**（`src/content/legal/*.md`），frontmatter 用 Zod 校验：
   `title`、`description`、`summary`、`effectiveDate`、`updatedDate`、`order`。
2. **条款内容逐字保留**，仅做必要的排版调整（列表结构、加粗、链接化邮箱）。
3. **新增一条隐私事实说明**（写入隐私政策「二、我们收集的信息」末段）：

   > 本网站（园枢官网）仅在您的浏览器本地保存浅色 / 深色主题偏好，用于还原显示设置；该偏好不会上传，清除浏览器数据即可删除。

   同时在「六、您的权利：数据如何删除」补充「在本网站清除浏览器站点数据，即可删除本地保存的主题偏好」。

4. **更新日期同步**：隐私政策 `updatedDate` 由 2026-09-25 更新为 2026-10-23（因为新增了上述说明）；用户协议内容未变，`updatedDate` 保持 2026-09-25。
5. **章节锚点**：使用 `rehype-slug` 生成 id，并用 `github-slugger` 在构建期生成目录（TOC）链接，**两者使用同一算法**，保证锚点必然匹配（E2E 已断言目录项可跳转并进入视口）。

## 理由

- Markdown + schema 让法律文本具备结构校验（缺字段即构建失败），比手写 HTML 更难出错；
- 目录与锚点显著改善长文可用性（v1 需要手动滚动）；
- **隐私声明必须与实现一致**：主题偏好是新增的本地存储，若不在隐私政策中说明，就构成「声明与实现不符」的合规风险。这是本次唯一实质性文本变更，且是「更保守」的方向（明示 + 可删除）；
- 用户协议未涉及网站端数据行为，故不改内容，保持生效日期不变。

## 替代方案

| 方案                                  | 否决理由                                                                     |
| ------------------------------------- | ---------------------------------------------------------------------------- |
| 保留手写 HTML，只加样式               | 无法做 schema 校验与目录自动化，长文维护成本高                               |
| 用 MDX 以便嵌入组件                   | 法律文本不需要组件，增加复杂度                                               |
| 不补充隐私说明                        | 会造成声明与实现不一致，属于合规缺陷                                         |
| 完全不使用 localStorage（只跟随系统） | 会丧失用户显式选择主题的能力（桌面浏览器常见的系统偏好与站点偏好不一致场景） |

## 影响

| 影响面 | 变化                                                                                |
| ------ | ----------------------------------------------------------------------------------- |
| 页面   | `/privacy.html`、`/agreement.html` 由内容集合生成，含目录、锚点、章节高亮、打印样式 |
| 元信息 | `article:published_time` 与 `modified_time` 来自 frontmatter；面包屑结构化数据同步  |
| 文本   | 隐私政策新增 1 段说明 + 1 条删除途径；其余条款逐字保留                              |
| 日期   | 隐私政策更新日期变更；用户协议不变                                                  |

## 风险与回滚

| 风险                             | 缓解                                                                                            | 回滚                                              |
| -------------------------------- | ----------------------------------------------------------------------------------------------- | ------------------------------------------------- |
| 迁移过程中条款被意外改动         | 迁移后逐章对照 v1 文本核对（章节数 9 / 7 由 E2E 断言）；v1 原文在 `backup/pre-refactor-v1` 分支 | `git revert` 对应提交                             |
| 新增说明被误解为「网站收集数据」 | 措辞明确「仅本地、不上传、可删除」                                                              | 删除该段并将主题改为仅跟随系统（需同步 ADR-0004） |
| 锚点与目录不匹配                 | 用同一 slug 算法生成（解决 v1 手写锚点易错的问题）                                              | —                                                 |
