# 架构决策记录（ADR）

每篇 ADR 包含：背景、候选方案、决策、理由、替代方案、风险与回滚方式。
决策一旦被后续 ADR 取代，将在原文件中标注「已被 ADR-XXXX 取代」，不删除历史。
