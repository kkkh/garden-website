# ADR-0004：配色与明暗主题 —— 独立校准 + 对比度门禁

- 状态：已采纳
- 日期：2026-10-23

## 背景

v1 只有浅色主题，设计语言为「墨蓝 × 鎏金 × 宣纸暖白」。任务要求：

- 文字/背景对比度至少 WCAG AA；
- 主色克制，中性色承担主体；
- hover/active/focus/disabled 状态完整；
- **暗色模式独立校准，不简单反色**；
- 输出颜色表、使用规则、禁用组合、对比度检查结果。

## 决策

1. **明暗两套语义色独立取值**，不通过反相或滤镜派生：暗色主题的画布、表面、文字、边框强度、品牌金亮度和阴影都单独定义（见 `src/design/tokens.ts` 的 `lightColors` / `darkColors`）。
2. **主题偏好三态**：`light` / `dark` / `system`，默认 `system`；偏好写入 `localStorage['garden:theme']`，无 JS 时由 `@media (prefers-color-scheme)` 兜底。
3. **首屏无闪烁**：`<head>` 中内联执行 `theme-init.ts`，在样式解析前写入 `data-theme`（E2E 已断言：`waitUntil: 'commit'` 时 `html[data-theme]` 已是目标值）。
4. **对比度自动化门禁**：`scripts/check-contrast.mjs` 使用 `culori` 计算 WCAG 对比度，覆盖 33 项组合，未达标即失败（退出码 1），并生成 `docs/design-system/contrast-report.md`。
5. **判定口径明确**：
   - 常规文本 ≥ 4.5:1（AA），并附带标注是否达到 AAA（7:1）；
   - 大号文本与交互组件边界/焦点指示 ≥ 3:1（WCAG 1.4.11）；
   - 纯装饰性发丝线按 WCAG 1.4.11 豁免，仅记录数值不参与判定（避免为「好看」牺牲层级，也避免为达标把发丝线做成粗黑框）。

## 关键校准结果

第一轮门禁直接暴露 v1 遗留问题：浅色主题下 10 项不达标，例如

| 用途 | 调整前 | 对比度 | 调整后 | 对比度 |
| --- | --- | ---: | --- | ---: |
| 次要文字 / 卡片 | `#3b4b67` | 3.46:1 ❌ | `#45516a` | 7.96:1 ✅ |
| 三级文字 / 卡片 | `#5b6a82` | 2.44:1 ❌ | `#5f6a7d` | 5.46:1 ✅ |
| 品牌强调 / 卡片 | `#98752f` | 2.14:1 ❌ | `#6f5220` | 7.23:1 ✅ |
| 链接 / 画布 | `#24466f`（原用 `--blue`） | 3.79:1 ❌ | `#24466f` 保持不变，改为该值 | 9.15:1 ✅ |
| 危险色 / 卡片 | `#a83f3f` | 2.99:1 ❌ | `#93322f` | 7.67:1 ✅ |
| 成功色 / 卡片 | `#2e6354` | 2.94:1 ❌ | `#24564a` | 8.38:1 ✅ |
| 交互边框 / 卡片 | `#a7b0bf` | 1.89:1 ❌ | `#7c889c` | 3.58:1 ✅ |

深色主题同步单独校准：`--color-text-tertiary` 用 `#93a0b0`（6.87:1），交互边框用 `#5f6f92`（3.63:1），强调色用 `#e2c987`（11.25:1）。

**深色底上的「墨区」单独处理**：`.hero` 与 `.section--ink` 内部覆盖 `--color-accent` 为 `gold-300`、`--color-text-secondary` 为 `hero-text-muted`，避免亮色主题的深金在深底上对比不足（浏览器实测：hero eyebrow 计算色为 `rgb(226, 201, 135)`）。

## 替代方案

| 方案 | 否决理由 |
| --- | --- |
| 只做浅色主题 | 不满足任务要求；且用户已习惯系统级深色 |
| 用滤镜/反相自动生成深色 | 会破坏金色与墨蓝的关系，文字对比不可控 |
| 手动检查对比度 | 不可重复、无法作为 CI 门禁，且容易漏 |
| 为达到 3:1 把发丝线加深 | 会破坏「宣纸 + 发丝线」的克制美学，WCAG 也未要求装饰线达标 |

## 影响

| 影响面 | 变化 |
| --- | --- |
| 视觉 | 浅色主题的次要文字、强调色、边框整体加深一档，可读性显著提升 |
| 主题 | 新增加三档主题切换控件（页头），带 `aria-pressed` 与 `title` |
| 对比度 | 33/33 项通过；两份报告随提交更新 |
| 打印 | 打印时强制浅色 `color-scheme: light`，并隐藏交互元素（见 `base.css` 打印区） |

## 风险与回滚

| 风险 | 缓解 | 回滚 |
| --- | --- | --- |
| 加深配色后「不如以前轻盈」 | 通过降低次要文字使用面积（改用 tertiary）与保持发丝线浅色来平衡；视觉基线可对比 | 回退 `tokens.ts` 中对应色值并重跑 `check:contrast` |
| 主题偏好被误认为「收集信息」 | 隐私政策已补充说明「仅本地保存主题偏好」 | 如需完全避免存储，可改为仅跟随系统（删除 localStorage 读写） |
| 深色模式下第三方图片（截图）刺眼 | 截图区背景始终为墨色舞台，与深色主题一致 | — |
